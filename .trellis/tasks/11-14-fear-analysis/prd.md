# 恐惧清单：可选权衡分析

## Goal

在恐惧清单的五步模型中加入一块可选的「权衡分析」，帮助用户在行动前判断这件事值不值得做，并通过「不行动的代价」对抗回避。

用户价值：恐惧会让人高估短期安全、低估长期代价。把收益和不行动的 6 个月 / 1 年 / 3 年代价写下来，行动才有依据。

## Background

现有五步：识别恐惧 → 寻找根因 → 定义问题 → 转化为任务 → 验证与反馈。

用户希望补充（最终范围）：

- 列出潜在好处
- 评估取得「至少还算不错」结果的把握
- 寻找「更普通的人也做到过」的历史案例
- 评估影响程度
- 计算「不行动」的代价：6 个月后 / 1 年后 / 3 年后

最初提出的「尝试的预期收益」1–5 评分在评审中被移除：孤立的主观收益分不改变决策，保留具体好处列表即可。

已确认的设计结论：不塞进第 2 步，而是放在第 3 步「定义问题」之后、第 4 步「转化为任务」之前，作为独立、可折叠的可选区块，不计入五步进度。原因：第 2 步是因果分析，这块是决策分析；顺序应为理解问题 → 权衡值不值得 → 承诺行动。

## Requirements

- R1 位置：详情页第 3 步和第 4 步之间，独立卡片「权衡分析（可选）」。
- R2 折叠：默认折叠；已有分析内容时自动展开；可手动展开 / 收起。
- R3 字段：
  - 潜在好处：文本列表，最多 3 条，可增删。
  - 把握程度：1–5，0 表示未评；问题为「你有多大的把握能取得一个『至少还算不错』的结果？」；再次点击已选值可清除。
  - 历史案例：文本输入；提示为「历史上，有没有比你更普通（甚至没你聪明）的人做过类似的事，并且成功了？」；要求写清是谁、做了什么、结果如何。
  - 影响程度：1–5，0 表示未评。
  - 不行动代价：三个文本输入，提示语如下：
    - 6 个月后：如果保持现状，半年后你的财务状况、情绪状态和身体健康会付出什么代价？
    - 1 年后：一年过去，如果你依然停留在原地，会错过哪些机会或产生怎样的遗憾？
    - 3 年后：三年后回望今天，维持现状会给你的人生带来多大程度的负面累积？
- R4 保存：复用详情页 800ms 防抖自动保存、版本守卫和离开补保存；不新增 API。
- R5 完成度：不计入 5/5 进度；折叠头部显示分析状态（未填写 / 已填写）。
- R6 兼容：旧记录缺少 `analysis` 时归一化为空；列表、归档、删除行为不变。
- R7 视觉：沿用语义 token 与 `card` / `field` / `chip` 共享类；不做复杂动画。

## Key Decisions

- D1 位置（2026-11-14）：第 3 步之后、第 4 步之前。理由：权衡是问题定义与行动之间的决策环节。
- D2 形态（2026-11-14）：独立可折叠区块，默认折叠，有内容自动展开。理由：小恐惧可以跳过，不增加五步负担。
- D3 存储（2026-11-14）：存 `FearData.analysis` JSON，不新增数据库列。理由：无需 migration，旧数据可由 `normalizeFearData` 兜底。
- D4 评分（2026-11-14，更新）：移除「尝试的预期收益」评分（用户反馈无实际决策价值）；保留「把握程度」与「影响程度」两个 1–5 评分，0 表示未评。
- D5 历史案例（2026-11-14）：新增文本字段，用「更普通的人也做到过」的具体案例对抗「我不够聪明」的自我叙事。

## Out of Scope

- 不新增第 6 步，不改五步导航与进度。
- 不自动计算或换算金钱代价。
- 不做必填校验。
- 暂不在列表卡片增加「已分析」标记。
- 不改变归档、删除、导出结构（`analysis` 随 `data` 自动导出）。

## Acceptance Criteria

- [ ] 详情页第 3、4 步之间出现「权衡分析（可选）」卡片。
- [ ] 默认折叠；已有分析内容时自动展开；可手动收起。
- [ ] 把握 / 影响程度 1–5 可选、可清除。
- [ ] 潜在好处最多 3 条，可增删。
- [ ] 历史案例可填写并随内容自动保存。
- [ ] 三段「不行动代价」提示语与需求一致。
- [ ] 输入后自动保存，刷新后内容完整保留。
- [ ] 旧记录（无 `analysis`）不报错，显示为空分析。
- [ ] 五步进度仍为 5；归档、删除、列表不受影响。
- [ ] `npm run typecheck` 与 `npm run build` 通过。
