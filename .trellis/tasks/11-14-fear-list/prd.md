# 恐惧清单：五步恐惧转化

## Goal

新增一个独立模块，把一条模糊的恐惧按五步模型拆解，最终转化为可执行的下一步行动，并用证据验证是否真的前进了一步。

用户价值：把回避变成行动。恐惧被写下来、拆开、变成任务之后，才有机会被验证，而不是一直在脑子里放大。

## Background

### 原始需求

- 独立的「恐惧清单」功能。
- 五步转换模型，形态上「大概就是 5 个输入框」：
  1. 识别恐惧
  2. 寻找根因，为什么害怕
  3. 定义问题，需要解决什么
  4. 转化为任务，下一步做什么
  5. 验证与反馈，我取得了什么证据？
- 可能是多条记录的清单。

### 仓库现状（已确认）

- 单用户应用，数据按 `user_id`（Access 邮箱）隔离；新数据必须进入 `/api/bootstrap` 与 `/api/export`。
- 「五步诊断」已有同类结构可参考：`goals` 表 + 列表页 + 详情页 + 五步 JSON + 800ms 防抖自动保存（`docs/goal-module-design.md`）。
- 需要列表、排序、独立 id 的实体应使用独立表；`documents(module, key)` 适合单篇、结构不固定的内容。
- 路由集中在 `src/App.tsx`，顶级导航在 `src/components/Layout.tsx` 的 `NAV`。
- 质量门为 `npm run typecheck` 与 `npm run build`，项目暂无自动化测试。

## Requirements

- R1 独立入口与列表：新增 `/fears` 页面，按更新时间倒序展示所有恐惧条目，并在顶级导航中加入「恐惧清单」。
- R2 新建流程：点击「新建恐惧」打开轻量弹窗，只填写第 1 步「我具体在害怕什么」；提交后创建记录并进入详情页 `/fears/:id`。
- R3 详情页字段：纵向依次展示五个输入框，顺序固定：
  1. 识别恐惧（我具体在害怕什么）
  2. 寻找根因（为什么害怕，追问到真正的原因）
  3. 定义问题（需要解决的是什么）
  4. 转化为任务（下一步具体做什么）
  5. 验证与反馈（我取得了什么证据）
- R4 列表标题：不设独立标题字段；标题取第 1 步内容的第一行，超出长度截断，空内容显示「未命名恐惧」。
- R5 记录管理：支持多条恐惧记录的新建、查看、编辑、删除。
- R6 自动保存：详情页输入停止 800ms 后自动保存；显示「保存中 / 已保存 · 时间 / 保存失败，可重试」；用版本守卫避免旧响应覆盖新输入；有未保存内容时离开页面给出提示并补一次保存。
- R7 派生状态：不新增显式状态字段，列表根据内容派生标签：
  - 第 4 步为空 → 「待行动」
  - 第 4 步有内容、第 5 步为空 → 「待验证」
  - 第 5 步有内容 → 「已验证」
- R8 删除：详情页删除需要二次确认，删除后返回列表并同步更新缓存。
- R9 持久化：恐惧数据写入 D1 新表，并随 `/api/bootstrap`、`/api/export` 返回。
- R10 视觉与文案：沿用现有语义 token 与共享类（`card` / `field` / `btn-*` / `chip`），五步文案与页面文案集中放到 `src/content/fears.ts`。

## Key Decisions

- D1 交互形态（2026-11-14）：列表页 + 独立详情页，详情页纵向五个输入框，不做分步向导。理由：列表可扫读，长文本有空间，且与现有五步诊断结构一致。
- D2 任务转化（2026-11-14）：第 4 步仅作文本记录，不与 `items` / `goals` 联动。理由：现有清单页尚未支持勾选完成，跨模块联动无法形成闭环，先保持 MVP 边界。
- D3 状态展示（2026-11-14）：不新增显式状态字段，也不做状态筛选；列表根据第 4、5 步派生「待行动 / 待验证 / 已验证」。
- D4 标题来源（2026-11-14）：用第 1 步内容作为列表标题，不增加独立标题输入。理由：严格保持五个输入框。

## Out of Scope

- 与「五步诊断」目标或「清单」模块联动。
- 显式状态字段与状态筛选。
- 提醒、通知、评分、AI 建议。
- 多用户共享或协作。
- 恐惧条目的拖拽排序、搜索、导入。

## Acceptance Criteria

- [ ] 顶级导航出现「恐惧清单」，点击进入 `/fears`。
- [ ] 可以在弹窗填写第 1 步并创建记录，创建后进入 `/fears/:id`。
- [ ] 详情页五个输入框顺序正确，输入后自动保存，刷新后内容完整保留。
- [ ] 列表标题取自第 1 步第一行；空内容显示「未命名恐惧」。
- [ ] 填写第 4 步后列表状态变为「待验证」，填写第 5 步后变为「已验证」。
- [ ] 删除有二次确认，删除后列表不再出现该条目。
- [ ] `/api/bootstrap` 与 `/api/export` 响应中包含 `fears` 数据。
- [ ] 现有模块（每日仪式、目标、复盘、清单、人生 OS、Reality OS）行为不受影响。
- [ ] `npm run typecheck` 与 `npm run build` 通过。
